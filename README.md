# Course Study Skills

面向课程学习、教材式讲义编写与考试复习的 Agent Skills 合集。

根据实际课件、课堂笔记和课程要求，将分散材料整理为可持续更新的学习笔记、结构完整的教材式讲义，或便于复习与开卷查阅的考试资料。三个技能可以独立使用，也可以在需要时衔接使用。

## 选择合适的技能

| 你的需求                                     | 技能                                                         | 组织方式与交付                                         |
| -------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------ |
| 跟随授课顺序整理日常笔记，保留知识细节和原图 | [course-notes](skills/course-notes/README.md)                | 尽量保留课程主线，默认输出面向 Typora 的 Markdown 笔记 |
| 缺少合适教材，希望把零散材料编成系统讲义     | [course-textbook-builder](skills/course-textbook-builder/README.md) | 建立知识结构和必要衔接，按需输出 Word、PDF 或 Markdown |
| 围绕课程范围和考试要求整理复习资料           | [course-exam-review](skills/course-exam-review/README.md)    | 知识点梳理、核心重点整理、试题预测与参考答案，允许多选 |

三个技能的区别在于任务目标，不只是文件格式。日常笔记强调忠于授课主线；教材讲义强调系统讲解；考试资料强调指定范围、重点和应用。无需为了使用其中一个技能而运行另外两个。

## 开始使用

1. 下载仓库，选择所需技能。
2. 将 `skills/` 下对应的整个技能文件夹安装到运行工具支持的技能目录，或使用该工具的技能导入功能。
3. 保留文件夹中的 `SKILL.md`、`references/`、`scripts/` 和其他已有资源的相对位置。
4. 在工具中选择或明确调用技能，提供材料并说明任务。

本仓库不是一个单独的技能：三个 `SKILL.md` 分别是三个技能的入口。若安装工具支持从仓库指定子目录安装，选择 `skills/course-notes` 等具体路径；不支持时分别导入三个文件夹。安装目录、调用语法和自动发现方式以所用工具的说明为准。

示例请求：

> 使用 course-notes 整理这一章课件，尽量保留授课顺序，完整保留知识点，例题采用原题和已有答案的清晰截图。

> 使用 course-textbook-builder，把这些课件与课堂笔记编成教材式讲义。输出 PDF 和 Word，重点讲清概念之间的联系，不明确的内容先询问。

> 使用 course-exam-review 整理考试资料。先询问我需要哪些模式，允许多选，并确认考试范围、题型和交付方式。

已明确的要求会沿用；影响范围、内容判断或交付的缺失信息应先确认。默认样式和常规技术实现不需要逐项询问。

## 可以得到什么

- 与课程实际内容相符的知识组织，保留必要定义、条件、公式、方法及例题。
- 专业、连贯的文字与适度强调，减少重复来源提示和无关编辑说明。
- 清晰的章节结构、图文关系和检索入口。
- 按任务要求进行内容、引用和成品检查，并明确实际完成的验证范围。

各技能默认策略不同。例如，日常笔记默认保留原题与原答案，不主动补充解题过程；教材式讲义保留理解所需的解释与推导；考试资料按题目要求组织参考答案。详细规则以各技能文件为准。

## 环境与工具

技能文件提供工作指令，不自带模型、OCR 服务、字体或文档排版引擎。文件读取、联网检索、Word/PDF 导出与渲染能力取决于运行环境。

可选用现有文档解析工具处理材料，但公式、复杂图表和扫描内容仍需核对。`course-notes` 附带一个仅依赖 Python 3 标准库的只读 Markdown 检查脚本；没有 Python 时可按规则人工检查。

仓库不绑定某个模型或特定运行工具。支持加载此类技能格式不等于已经验证所有平台上的端到端表现。

## 仓库结构

```text
course-study-skills/
├── README.md
├── DESCRIPTION.md
└── skills/
    ├── course-notes/
    │   ├── SKILL.md
    │   ├── README.md
    │   ├── agents/
    │   ├── references/
    │   └── scripts/
    ├── course-textbook-builder/
    │   ├── SKILL.md
    │   ├── README.md
    │   └── references/
    └── course-exam-review/
        ├── SKILL.md
        ├── README.md
        └── references/
```

`README.md` 面向使用者；`SKILL.md` 面向执行技能的代理；`references/` 保存按需读取的详细规则；`scripts/` 保存必要的可执行辅助工具。各技能的辅助资源保存在自己的目录内，便于独立安装。
