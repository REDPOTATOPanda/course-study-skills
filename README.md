# Course Textbook Builder

**将零散授课材料编写成结构完整、讲解连贯的教材式课程讲义。**

当课程没有指定教材，或教师实际讲授的内容与教材关联较弱时，学习资料往往分散在课件、课堂笔记和补充讲义中。Course Textbook Builder 是一个可供兼容宿主使用的 Agent Skill，指导 AI 按知识之间的联系重组这些材料，讲清概念、原理与方法，并形成适合学习、复习、查阅和长期留存的课程讲义。

以实际授课材料为依据，保留必要的定义、公式、适用条件、推导、流程和典型例题；通过统一的章节结构与排版，让讲义具有教材式的连续阅读体验。开卷考试是其中一种使用场景，也可用于日常课程学习和复习。

## 适用场景

- **缺少指定教材**：教师主要使用 PPT、PDF 或自编讲义授课，需要建立完整的知识框架。
- **教材与授课内容脱节**：课程内容来自多个来源，现有教材无法完整对应实际讲授范围。
- **资料零散或重复**：同一主题分布在多份课件和笔记中，需要归并、解释并厘清关系。
- **准备复习与查阅资料**：希望保留原理、条件和例题，同时通过目录、关键词和公式快速定位。
- **持续维护课程讲义**：后续补充章节或修订局部内容，需要保持术语、版式、目录与页码一致。

如果只需要解释一个概念、做一份简短摘要或预测试题，通常不必启用完整的教材编写流程。

## 可以得到什么

| 方面 | 预期效果 |
| --- | --- |
| 知识结构 | 按“章—节—小节”组织内容，连接先修知识、概念、原理、方法与应用 |
| 正文讲解 | 连贯解释知识与方法，保留必要的公式、条件、推导和典型例题 |
| 方法比较 | 从目标、原理、流程、适用条件及局限等角度解释差异与演进 |
| 阅读与检索 | 准确的标题、清晰的目录、适度加粗的关键短语，以及必要的交叉引用 |
| 成品排版 | 协调的课程封面、独立目录、统一字体字号、清楚的公式图表和自然分页 |
| 持续更新 | 局部修改后同步相关定义、引用、目录及页码，保留未修改的实质内容 |

支持按需输出 **Word、PDF 或 Markdown**。输出格式由使用者指定；实际文件生成及渲染检查取决于 AI 宿主提供的工具和运行环境。

## 快速开始

1. 将本仓库的技能文件安装到所用宿主的技能目录，保留 `SKILL.md` 与 `references/` 的相对位置。
2. 上传课程材料，或向具有本地文件权限的 AI 提供材料路径。
3. 明确课程名称、整理范围、使用目的和输出格式，然后调用技能。

例如：

```text
请使用 course-textbook-builder，根据我提供的课程课件和课堂笔记，
编写一本教材式课程讲义。

课程名称：计算机视觉
整理范围：本次提供的全部材料
使用目的：日常学习、期末复习与开卷查阅
输出格式：PDF

以实际授课内容为主要依据，保留必要的定义、原理、公式、
适用条件、步骤与典型例题，并建立知识之间的联系。
正文采用连贯的教材式讲解，重点适度加粗。
封面、目录和正文按技能中的统一样式排版。
遇到影响正确性或课程范围的疑点，请先向我确认。
```

项目级安装用于某一项目；用户级安装用于个人的多个项目。不要把 `references` 留在技能文件夹之外。安装后检查宿主的技能列表；若未发现技能，先核对目录层级和文件名，并按宿主要求刷新或重启。

## 如何提供材料

可提供宿主能够读取的 PPT/PPTX、PDF、Word、Markdown、课堂笔记和补充知识点。扫描件或图像型课件需要视觉读取或 OCR 能力；具体文件支持情况取决于可用解析工具。

为了让结果更贴合课程，建议同时说明：

| 信息 | 示例或说明 |
| --- | --- |
| 课程名称与范围 | 整门课程、指定章节，或列出的几份材料 |
| 使用目的 | 初次学习、系统复习、开卷查阅或长期留存 |
| 教师明确要求 | 已知重点、考查范围、特定符号约定；没有则无需补写 |
| 内容修改边界 | 是否允许合并重复内容、纠错或添加必要的衔接解释 |
| 输出要求 | Word、PDF、Markdown；如需多种格式，请明确列出 |
| 版式依据 | 学校模板、出版物样例、纸张尺寸、装订或打印要求 |

没有指定模板时，技能提供 A4 竖版单栏的排版起点；这是一套可调整的方案，并非通用于所有出版物的统一标准。

## 默认编写与排版方式

### 内容组织

从课程整体问题和知识依赖出发设计章节，把分散材料归入合适的位置。第一章通常安排为概述或导论，但不机械增设空泛章节。已有合理课程结构时，尊重材料并作必要优化。

概念解释以连贯段落为主；算法流程和操作步骤使用编号，适合并列比较的内容使用表格。关键定义、结论、条件和区别可适度加粗，避免整段强调。

保留内部来源与覆盖记录以便核对，正文不逐个知识点附加来源标签或制作说明。遇到实质性缺失或矛盾时，先向使用者确认处理方式；最终成稿不保留未解决的编辑标记。必要的学术引文、图表署源以及知识本身的适用条件仍应保留。

### 页面结构

```text
课程封面
    ↓
   目录
    ↓
第1章：从新页开始
    ↓
第2章：从新页开始
    ↓
后续章节
```

封面采用有层次的标题、协调配色或与课程相关的图形；学校、教师等信息仅在提供后使用。

目录按章组织并列出必要层级。每章另起新页，章内各节与知识点自然连续排版，不为对称或视觉整齐反复分页。目录过长时优先精简显示层级，仍无法容纳必要条目时向使用者确认处理。

正文、标题、图表题注及公式使用统一样式。默认正文约 11 pt，中文采用宋体类字体，标题采用黑体类字体，西文及数学字体按用途配置；有用户模板时优先遵循。含分式、矩阵和上下标的公式保留足够行高，图片保持比例。

具体规则见 [版式与格式实现](references/layout.md)。

### 输出与检查

| 输出 | 重点要求 |
| --- | --- |
| Word | 原生标题与段落样式，优先使用可编辑公式，并同步目录和页码 |
| PDF | 文本可检索，字体与公式显示正常，目录页码准确；尽可能提供跳转与书签 |
| Markdown | 清晰的标题、公式和图片路径，并提供对应的导出样式或设置 |

生成后检查内容覆盖、公式符号、图表比例、分页及目录引用。能渲染的成品应实际渲染检查；环境无法完成的验证应明确说明，不能仅凭文件成功保存就声称排版已验证。

## 其他使用示例

### 先整理知识结构

```text
请使用 course-textbook-builder，先阅读我提供的材料，
梳理整体知识结构和章节之间的依赖关系。
本次先输出章节设计与内容组织，不生成 Word 或 PDF。
```

### 整理已有成稿

```text
请使用 course-textbook-builder 整理这份已有讲义。
保留全部实质内容，不新增知识点或删除例题，
只优化章节层级、内容位置和排版，输出 Word 与 PDF。
如发现需要实质性纠错的内容，请先向我确认。
```

### 更新指定章节

```text
请使用 course-textbook-builder，只更新第3章。
依据新补充的材料完善相关内容，保留其余章节的实质内容，
并同步受影响的交叉引用、目录及页码，保持整本讲义样式一致。
```

## 工具与效率

技能可按材料类型选择解析方式。已有清晰文本时直接读取；适合转换的 Office、HTML 或混合材料，可选用 [Microsoft MarkItDown](https://github.com/microsoft/markitdown)；扫描页和复杂图文则按需使用 OCR、视觉读取或其他适配工具。

MarkItDown 是可选的前处理工具，不是运行本技能的强制依赖，也不负责教材内容编写或最终排版。名为 `markitdown` 的第三方技能不等同于微软官方工具。

为减少重复处理，技能指导 AI：

- 缓存材料提取结果，在输入或转换设置变化后重新处理。
- 先建立全局知识地图，再按章节读取完整的相关片段。
- 用覆盖映射核对定义、条件、公式、图表和例题，防止遗漏。
- 局部修订时重建受影响内容，并检查相关引用与后续分页。
- 在需要排版时才读取详细样式规则。

这些是工作流程指导，并非仓库内置的自动缓存引擎；具体执行由宿主与工具承担。效率取决于材料、模型和运行环境，当前不承诺固定的 token 节省比例。

## 能力边界

本项目是指导 AI 执行任务的技能包，实际结果依赖模型的理解能力、材料质量及宿主的工具权限。文档生成需要可用的文件处理工具和字体，最终排版验证还需要渲染能力。

转换成功不代表公式、图片或多栏阅读顺序一定准确，关键内容仍需核对原件。补充解释不能冒充教师已讲授的内容；教师未明确给出的考试重点，也不能写成确定范围。

技能文件不预设固定章数或页数，不保证达到正式出版审校水平，也不代替使用者对学术准确性及课程要求的最终核对。
