# Course Study Skills

面向课程学习、教材式讲义编写与考试复习的 Agent Skills 合集。

本项目以实际授课材料为基础，将课件、课堂笔记与零散知识整理为结构清晰、内容准确、便于理解和查阅的学习资料。三个技能分别服务于日常笔记、系统讲义和考试复习，可以独立使用，也可以根据需要衔接使用。

## 技能概览

| 技能 | 适用场景 | 核心目标 | 输出形式 |
|---|---|---|---|
| [course-notes](skills/course-notes/README.md) | 跟随课程学习，整理章节课件与补充材料 | 保留授课主线，完整覆盖知识，结合原图形成可持续更新的笔记 | 默认 Markdown，面向 Typora |
| [course-textbook-builder](skills/course-textbook-builder/README.md) | 缺少合适教材，或实际授课与教材关联较弱 | 将零散材料编写为结构完整、讲解连贯的教材式课程讲义 | 按需输出 Word、PDF 或 Markdown |
| [course-exam-review](skills/course-exam-review/README.md) | 根据课程范围、教师重点和考试要求准备复习资料 | 梳理知识、集中讲解重点、编写预测题与参考答案 | 按需输出 Word、PDF 或 Markdown |

## 如何选择

### 整理日常课程笔记

选择 **course-notes**。

适合逐章整理课件、补充已有笔记或修改指定内容。尽可能保留授课顺序和知识层级，保留必要的定义、公式、条件、算法与原图，并合并重复讲解。

例题默认保留原题与已有答案，优先使用清晰截图；可根据要求改为可编辑内容或增加解题讲解。

### 编写系统的课程讲义

选择 **course-textbook-builder**。

适合将分散的课件、笔记和知识点组织成可独立阅读的讲义。围绕知识之间的联系安排章节，讲清概念、原理、方法、适用条件与必要推导，避免逐页照搬课件。

支持统一封面、目录、标题、公式、图表与分页，兼顾学习、查阅和长期留存。

### 准备考试复习资料

选择 **course-exam-review**。

支持三种模式，允许组合使用：

- **知识点梳理**：按章节组织，保留理解与应用必需的内容。
- **核心重点整理**：围绕明确重点集中展开，减少分散查找。
- **试题预测与参考答案**：依据实际要求整理简答、计算、选择、填空等题型。

开始前确认模式及关键考试要求，不预设题型、题量、分值或考试难度。

## 设计原则

### 以实际课程为依据

优先遵循课件、课堂笔记和教师明确要求。保留定义、前提、符号、公式与结论的适用范围，不把常见考试套路或外部知识直接当作本课程重点。

### 保留理解所需的内容

精简重复表达，保留必要解释、推导、方法和例题。知识整理应帮助读者理解与应用，而不只是形成结论清单。

### 对重要歧义先确认

涉及材料缺失、内容冲突、整理范围或交付要求的实质性问题，应先询问用户。已经明确的要求直接沿用，不重复确认。

### 保持专业、连贯的呈现

正文直接陈述知识，避免反复出现“课件中说”等来源提示和无关编辑说明。概念解释采用连贯段落，流程合理编号，比较内容适当使用表格，关键内容适度加粗。

### 区分检查与验证

材料提取、结构检查、内容核查和实际渲染属于不同环节。文本能够提取，不代表公式准确；文件能够打开，也不代表排版合格。交付时应如实说明实际完成的检查。

## 快速开始

### 1. 获取技能

下载本仓库，将所需技能的完整文件夹安装到运行工具支持的技能目录，或通过其技能导入功能加载。

每个技能均位于 `skills/` 下，并拥有独立的 `SKILL.md` 入口。安装时保留对应目录内的 `references/`、`scripts/` 等资源及其相对路径。

本仓库是技能合集，不是单个技能。如果安装工具支持指定仓库子目录，请选择具体路径，例如：

```text
skills/course-notes
skills/course-textbook-builder
skills/course-exam-review
```

具体安装位置、调用语法和自动发现方式，以所用运行工具的说明为准。

### 2. 提供材料与任务

选择或明确调用相应技能，提供课件、笔记或已有文档，并说明整理目标。影响结果的信息不足时，技能会先询问。

可以直接使用以下请求：

**日常笔记**

> 使用 course-notes 整理这一章课件，尽可能保留授课顺序，完整保留知识点和必要原图，例题使用原题与已有答案的清晰截图。

**教材式讲义**

> 使用 course-textbook-builder，将这些课件与课堂笔记编写成系统讲义，讲清概念之间的联系，保留必要原理和例题，输出 Word 和 PDF。不明确的内容先询问。

**考试复习**

> 使用 course-exam-review 整理这门课的复习资料。先询问我需要哪些模式，允许多选，并确认考试范围、题型和交付方式。

**局部更新**

> 使用 course-notes 更新现有笔记，只补充附件中的新增内容，保留其他内容、批注和图片。

### 3. 检查并迭代

根据实际成果反馈内容深度、组织方式或排版问题。局部修改应保留无关内容，并重新检查受影响的公式、图片、引用与分页。

三个技能不要求按固定顺序运行。已有合适材料时，可以直接进入讲义编写或考试复习。

## 工作效率

技能在保证内容质量的前提下，采用以下方式减少重复处理：

- 按需读取章节、页段和参考规则，避免反复加载无关材料。
- 缓存提取结果，并依据材料内容及解析设置判断是否可以复用。
- 局部更新时处理相关内容，同时检查受影响的引用和结构。
- 根据材料类型选择解析工具，对公式、复杂图表及识别不可靠的部分回看原页。
- 将机械检查与知识判断分开，把人工核查集中在概念、条件、推导和图表含义上。

`course-notes` 还支持课程级偏好记录，并附带只读 Markdown 检查脚本。该脚本可以检查常见图片路径、标题跳级、代码围栏及占位标记，但不替代内容审核和实际渲染。

## 环境与输出

本项目提供技能指令、参考规范与必要的辅助脚本，不自带模型、OCR 服务、字体或文档排版引擎。

实际可用能力取决于运行环境：

| 工作环节 | 所需能力 |
|---|---|
| 读取课件与文档 | 对应文件格式的解析能力 |
| 处理扫描件或复杂图示 | OCR、图像读取或页面渲染能力 |
| 检索外部教材与参考资料 | 联网检索能力 |
| 生成 Word 或 PDF | 文档生成、数学排版与导出能力 |
| 检查最终版面 | 对应格式的渲染或预览能力 |
| 运行笔记检查脚本 | Python 3 |

可按需使用 MarkItDown 等现有工具进行初步解析，但转换结果仍需核对。工具支持加载技能格式，不等于已经验证其全部文档处理与导出功能。

## 仓库结构

```text
course-study-skills/
├── README.md
├── DESCRIPTION.md
└── skills/
    ├── course-notes/
    │   ├── SKILL.md
    │   ├── README.md
    │   ├── agents/
    │   ├── references/
    │   └── scripts/
    ├── course-textbook-builder/
    │   ├── SKILL.md
    │   ├── README.md
    │   └── references/
    └── course-exam-review/
        ├── SKILL.md
        ├── README.md
        └── references/
```

| 文件或目录 | 用途 |
|---|---|
| 根目录 `README.md` | 介绍合集、技能区别和使用方式 |
| `DESCRIPTION.md` | 提供可填写到 GitHub 的仓库简介 |
| 各技能 `README.md` | 说明具体场景、用法与预期成果 |
| `SKILL.md` | 技能入口，包含描述、流程与核心约束 |
| `references/` | 按需读取的详细写作、排版与工作规范 |
| `scripts/` | 可执行的辅助检查工具 |
| `agents/` | 特定运行工具使用的界面元数据 |

各技能将必要资源保存在自身目录内，便于独立安装与维护。

## 反馈与改进

欢迎针对知识组织、材料解析、内容遗漏、公式图表、排版效果或工具兼容性提出问题。

为便于复现，建议提供：

- 使用的技能及运行环境。
- 任务要求与预期结果。
- 实际出现的问题。
- 能够复现问题的最小材料或截图。

提交前请移除不必要的个人信息，并确认材料可以公开分享。涉及技能行为调整时，应区分某门课程的特殊要求与适用于一般课程的规则。
