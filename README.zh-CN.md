# Course Study Skills

[English](README.md) | [简体中文](README.zh-CN.md)

**课件太零散、教材对不上、复习资料来不及整理？把课堂材料变成能学懂、能复习、能快速查阅的课程资料。**

Course Study Skills 提供三个可独立使用的 Agent Skills，帮助你将 PPT、课堂笔记和补充讲义整理成课程笔记、教材式讲义或考试复习资料。

## 这些情况，你可能也遇到过

### 老师只发 PPT，翻完还是串不起知识

定义在一页，公式在另一页，重要条件藏在图里。逐页阅读能看懂局部，却难以形成完整认识。

使用 **Course Notes**，按授课主线整理概念、原理、公式与原图，保留必要解释，形成可持续补充的 Markdown 笔记。

### 有教材，但课堂讲的内容与教材对不上

知识分散在课件、课堂笔记和补充材料中，找不到一本真正对应这门课的参考书。

使用 **Course Textbook Builder**，将这些材料组织成结构连贯的教材式讲义，讲清知识之间的联系，便于系统学习和长期留存。

### 快考试了，资料很多，却不知道怎么组织

课件厚、重点散，临时总结容易只剩结论；开卷时虽然带齐资料，仍然很难快速找到需要的内容。

使用 **Course Exam Review**，围绕考试范围和明确重点，选择知识点梳理、核心重点整理或试题预测与参考答案，形成层级清楚、便于查阅的复习资料。

### 已经整理了一部分，不想每次都推倒重来

新课件、补充说明和自己的批注不断增加，重新生成整份文档容易覆盖已有成果。

三个技能都支持在明确范围内更新内容，保留无关文字、批注与图片，让资料随着课程推进持续积累。

## 为什么选择 Course Study Skills

### 覆盖从课堂学习到考试复习的不同需求

日常笔记、系统讲义和考试资料各有侧重。三个技能分别保留授课主线、建立知识体系或围绕考试要求组织内容，可以独立使用，也能随着学习进度衔接使用。

### 保留理解过程，不止提取结论

整理定义和公式时，同时保留必要的前提、变量含义、原理联系与推导。既方便快速查阅，也帮助理解方法为什么成立、何时适用，以及与相近概念有什么区别。

### 以你的实际课程为依据

优先使用课件、课堂笔记与教师要求，沿用课程中的术语和符号。遇到材料缺失、相互矛盾或要求不明确时先确认，减少通用知识与实际授课内容脱节的问题。

### 内容组织与文档呈现一起考虑

根据资料用途安排层级、目录、公式、图表和例题。考试复习技能配有三种模式的固定样例与共享样式，帮助不同任务保持清晰、一致的呈现，兼顾连续阅读和开卷查阅。

### 支持持续更新，保留已有成果

可以逐章整理、补充新增材料，或仅修改指定部分，保留无关内容、批注与图片。适合随着课程推进不断积累，而不是每次重新生成整份资料。

### 可编辑、可检查、便于长期留存

按需生成 Markdown、Word 或 PDF。将内容核对与版面检查分别落实，对公式、图表、引用和最终分页进行相应检查，便于后续修改、打印与归档。

## 选择适合你的技能

| 你的目标 | 使用技能 | 主要成果 |
|---|---|---|
| 跟随课堂学习，把课件整理成完整笔记 | [course-notes](skills/course-notes/README.zh-CN.md) | 保留授课主线、知识细节和原图的 Markdown 笔记 |
| 将零散材料编成可以独立学习的系统讲义 | [course-textbook-builder](skills/course-textbook-builder/README.zh-CN.md) | 结构完整、讲解连贯、统一排版的教材式讲义 |
| 围绕考试范围准备复习与开卷查阅资料 | [course-exam-review](skills/course-exam-review/README.zh-CN.md) | 知识梳理、核心重点或题目与参考答案 |

你可以只选择当前需要的一个技能，也可以在平时整理笔记、需要时编写讲义、考前准备复习资料，无需按固定顺序使用。

### Course Notes · 课程笔记

适合日常跟课、逐章整理和持续更新已有笔记。

沿用课程的讲授顺序与知识结构，保留定义、原理、条件、公式及必要原图，合并重复内容，补足理解所需的简短联系。原材料中的例题与答案按要求保留，也可以转换为可编辑内容。

默认输出面向 Typora 的 Markdown。只有明确要求时，才额外导出 Word 或 PDF。

### Course Textbook Builder · 教材式讲义

适合课程缺少合适教材，或实际授课内容与教材联系较弱的情况。

将分散的课件、笔记与知识点组织成“章—节—小节”的完整结构，解释概念之间的联系，保留必要原理、推导、适用条件与例题，形成可以独立阅读的课程讲义。

支持统一封面、目录、字体、公式、图表与分页，可按需输出 Word、PDF 或 Markdown。

### Course Exam Review · 考试复习资料

支持三种可组合模式：

- **知识点梳理**：按章节建立知识体系，保留理解与应用必需的内容。
- **核心重点整理**：围绕明确重点分层展开，将相关概念、原理、公式与方法比较集中组织。
- **试题预测与参考答案**：根据实际考试要求编排题目与答案，支持简答、计算、选择、填空等题型。

开始前确认所需模式、范围和输出要求。默认采用紧凑、清晰的单栏排版，也可根据打印需要选择双栏。

## 开始使用

### 1. 下载并安装

从[最新发布](https://github.com/REDPOTATOPanda/course-study-skills/releases/latest)获取所需技能，或下载全部技能合集。

解压后，将完整技能文件夹安装到所用 Agent 支持的技能目录，或通过其技能导入功能加载。请保留文件夹内的 `SKILL.md`、`references/`、`assets/` 和 `scripts/` 等配套资源。

也可以获取仓库源码：

```bash
git clone https://github.com/REDPOTATOPanda/course-study-skills.git
```

三个技能位于：

```text
skills/
├── course-notes/
├── course-textbook-builder/
└── course-exam-review/
```

具体安装位置与调用方式，以所用工具的说明为准。

### 2. 提供材料并描述任务

提供课件、课堂笔记或已有文档，说明希望整理的范围与成果。要求尚未明确时，Agent 应先询问，再开始相关编写。

**整理课程笔记**

> 使用 course-notes 整理附件中的第三章课件，保留授课顺序、全部有效知识和必要原图，输出 Markdown。原有例题保留题目与已有答案，不额外增加解题讲解。

**编写教材式讲义**

> 使用 course-textbook-builder，将这些课件和课堂笔记编成一份系统讲义，讲清概念之间的联系，保留必要公式、原理和例题，输出 PDF。材料存在矛盾时先问我。

**准备考试复习资料**

> 使用 course-exam-review，制作“核心重点整理”和“试题预测与参考答案”，合并为一份 PDF。考试范围和教师重点见附件；开始前先确认尚不明确的要求。

**更新已有内容**

> 更新这份笔记，只补充新课件涉及的内容，保留其他文字、批注和图片。

### 3. 查看并调整成品

可以继续指定需要修改的章节、解释深度、例题处理或排版方式。已有文档支持局部更新，无需每次重新整理全部内容。

生成 Word 或 PDF 时，在环境允许的情况下实际渲染检查公式、图表与分页，并分别核对内容和呈现效果。

## 运行环境与语言

这些技能需要能够读取材料、编写文件并加载技能指令的 Agent 环境。生成 Word、PDF、处理扫描件或检索外部资料时，还需要相应的文档、识别或联网能力。具体依赖见各技能 README。

技能执行规范采用英文，使用说明提供中英文版本。**成品语言遵循用户要求与课程材料**；课程笔记默认面向中文学习场景。
