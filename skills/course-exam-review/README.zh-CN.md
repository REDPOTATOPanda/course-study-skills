# Course Exam Review

[English](README.md) | [简体中文](README.zh-CN.md)

根据课程课件、课堂笔记、教师重点与考试要求，编制层级清楚、便于理解和查阅的专业复习资料。支持知识点梳理、核心重点整理、试题预测与参考答案三种模式，可组合使用，按要求输出 Markdown、Word 或 PDF。

## 使用

将完整的 `course-exam-review` 文件夹放入所用 agent 支持的技能目录，保留 `SKILL.md`、`references/`、`assets/` 和 `scripts/` 的相对结构。具体发现和调用机制以运行环境为准；本技能不依赖某一模型或私人文件路径。

提供课程材料，并说明模式、范围、考试信息及输出要求。例如：

> 使用 course-exam-review，根据附件编制核心重点整理与简答题参考答案，合并为 PDF。重点以教师给出的范围为准，使用单栏。

尚未说明的关键要求，agent 应先询问。模式不自动全选，不默认某门课程的题型、分值或考试结构。原材料已有例题按范围保留；知识点与核心重点模式下，新增解释性例题需用户提出或同意。双栏紧凑排版需明确选择。

## 固定产出风格

默认黑白、A4、单栏、紧凑连续排版。目录独立，页码右对齐；正文有明确层级，概念用段落说明，真实步骤才编号。页眉不显示题号范围。共享样式统一字体、间距、表格与公式，专业数学排版留足上下标和分式空间。

三种固定样例位于 `assets/examples/`，各有 PDF 与可编辑 JSON 内容源。样例只展示风格，不限定知识主题、题量、分值或页数。具体读取顺序、模板用法与验收要求见 `references/style-examples.md`。

`assets/templates/compact-review.json` 提供共享样式参数；`scripts/render_review.py` 是可选的单栏 PDF 参考渲染器。使用它时需要 Python 3、reportlab、svglib，数学块还需 Node 与 mathjax-full 3.x；字体由本地配置指定，字体文件与第三方运行库不随包分发。可使用等效工具完成 Word、Markdown 或 PDF，但应对照固定样例落实风格和实际检查。

## 质量与边界

内置缺漏分类、已有题目反查、可计算内容核验、具体验收及按需协作。它们用于提高可靠性，不授权扩写、自动押题或修改课程范围。内容准确性、完整性与最终渲染分别检查；用户模板和明确要求优先。

固定样例使用新编的算法知识，不含用户私人资料。不同字体、引擎与环境可能影响换行和分页，需要实际验证，不承诺跨平台逐像素一致。
